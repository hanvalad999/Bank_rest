# Postman: Bankcards API

## Импорт

1. Откройте Postman.
2. **Import** → выберите файл `Bankcards_API.postman_collection.json` (или перетащите его в окно).
3. Коллекция **Bankcards API** появится в боковой панели.

## Переменные коллекции

| Переменная   | Описание |
|-------------|----------|
| `baseUrl`   | Базовый URL API (по умолчанию `http://localhost:8080`). Меняйте, если приложение на другом порту (например, `http://localhost:18080`). |
| `token`    | JWT для авторизации. Заполняется автоматически после **Login (admin)** или **Login (user)**. |
| `adminToken` | Токен админа (сохраняется при логине админа). |
| `userToken`  | Токен пользователя (сохраняется при логине пользователя). |

У коллекции включён **Bearer Token** по переменной `token`, поэтому после успешного логина все запросы отправляются с этим токеном.

## Порядок проверки

1. **Запустите приложение** (и PostgreSQL). Убедитесь, что админ создаётся при старте (см. `app.admin.username` / `app.admin.password` в конфиге или переменных окружения).

2. **Auth**
   - **Login (admin)** — подставьте логин/пароль админа из конфига. Токен сохранится в `token`.
   - **Register** — создайте пользователя `testuser` / `password123` (или свои данные).
   - **Login (user)** — войдите как этот пользователь; токен сохранится в `userToken`.

3. **Users (ADMIN)** — выполнять с токеном админа (сначала **Login (admin)**):
   - Create user, Get users, Delete user.

4. **Cards**
   - **Create card (ADMIN)** — с токеном админа. Подставьте существующий `userId` (например, 1 или id созданного пользователя).
   - **Get all cards**, **Get card by id**, **Get balance**, **Update card status**, **Delete card** — для админа.
   - **Get my cards**, **Request block** — для пользователя (переключите `token` на `userToken` или выполните **Login (user)**).

5. **Transfers (USER)** — с токеном пользователя:
   - **Transfer** — `fromCardId` должна быть картой этого пользователя; укажите `toCardId` и `amount`.

## Учётные данные по умолчанию в запросах

- **Login (admin):** `admin` / `admin` — замените на значения из `app.admin` в конфиге приложения.
- **Register / Login (user):** `testuser` / `password123` — замените при необходимости.

При необходимости измените `baseUrl` (например, на `http://localhost:18080`), если приложение слушает другой порт.
